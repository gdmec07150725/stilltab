# Flutter移动端 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development or superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 在D盘交付能本地体验的Android规则App及诚实标注验证状态的iOS适配工程。
**Architecture:** Flutter管理页通过固定MethodChannel访问平台服务；Kotlin原生引擎执行Android规则并唯一持久化；Swift适配Apple真实系统API。
**Tech Stack:** Flutter/Dart、Kotlin、Android AccessibilityService、Swift Screen Time。
**Spec:** docs/mobile/设计.md；接口见 docs/mobile/平台接口.md。

## Global Constraints
源码apps/mobile；SDK D:/code/.tools；缓存D:/code/.cache。保留现有插件。默认中文、本机数据、无默认启用规则、不上传。最小Android26；iOS16。Android包标识com.behaviorrules.mobile。不依赖Flutter界面存活执行规则。不得默认启用无障碍、Root、锁定用户退出。Android与iOS配置不能混用。

## Review Focus
- 跨午夜分钟分段和零点额度重置，锁屏/服务重启不补计离线时长。
- 键盘/系统弹窗/自身遮罩不被当作重新打开目标App，离开应用取消旧遮罩。
- 导入不可信配置的类型/范围/重复ID/不支持动作，失败不破坏旧数据。
- 多规则冲突，单条临时放行不屏蔽其他规则。
- 权限撤销、保存/删除规则后旧遮罩清理，用户可进入设置退出保护。
