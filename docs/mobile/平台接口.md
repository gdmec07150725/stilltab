# 移动端平台接口（实现契约）

MethodChannel 名称 `behavior_rules/platform`。所有参数是String-key Map；返回JSON兼容类型，不返回JSON字符串除显式标注的方法。失败抛PlatformException(code,message)，UI显示中文错误。原生端必须验证输入，Flutter校验不能代替原生校验。

## 数据类型
- Target: `{platform: 'android'|'ios', id: string, label: string}`。label长度1..255。Android id是包名；iOS id是保存在AppGroup中的FamilyActivitySelection集合ID，label是用户可读集合说明。多个Target构成应用组，不跨平台。
- Rule: `{id,name,enabled,targets:Target[],exceptions:Target[],schedule:{enabled,days:[0..6],start:'09:00',end:'18:00'},quotaMinutes:0..1440,action:'remind'|'delay'|'block',delaySeconds:1..3600,message,buttonText,priority:-1000..1000,createdAt:epochMs}`。id限`[a-zA-Z0-9_-]{1,80}`，name1..80，message1..1000，buttonText1..40；id唯一，targets1..100，exceptions0..100。目标id1..255，不允许重复目标。days非空且不重复。timestamp为0..8640000000000000的有限整数；数值按数学整数校验，1.0可接受但不能截断小数。所有字段必需，未知额外字段可忽略。
- Config: `{version:1,platform:'android'|'ios',rules:Rule[]}`（最多200规则，序列化2MiB）
- Log: `{at:epochMs,ruleId,ruleName,targetLabel,action,reason}`，新记录在前，上限300。action可为remind/delay/block/bypass。
- Status: `{platform,permissionGranted:bool,monitoring:bool,availability:'ready'|'permissionRequired'|'unavailable',message:string,batteryOptimized:bool,lastEventAt:epochMs,capabilities:{appSelection:bool,remind:bool,delay:bool,block:bool,schedules:bool,quotas:bool,exceptions:bool}}`
- State: `{config:Config,usage:{'yyyy-MM-dd':{ruleId:milliseconds}},grants:{ruleId:expiresAtMs},logs:Log[],status:Status,today:'yyyy-MM-dd',now:epochMs}`
- Android listApps: Target[]，仅可启动且不属于必要系统组件的实际安装应用，按中文可读标签排序。无需传输图标，UI可用首字图标。

## 方法
- `getState()` -> State。权限/连接状态实时读取；UI每3秒及onResume刷新，避免覆盖正在编辑表单。
- `listApps()` -> Target[] (Android)。iOS用pickTargets。
- `pickTargets({selectionId?:string})` -> Target[]|null (iOS)。系统选择器确认返回一个opaque selection Target，取消null。
- `saveRule({rule:Rule})` -> State；新增/覆盖，清除该rule单次状态/grant/wait，更新在前台的执行；不清除正常编辑的当日用时。
- `deleteRule({id})` -> State；移除相关grants/waits/usage，清除执行中的遮罩。
- `toggleRule({id,enabled})` -> State；清除该rule会话/grant/wait；保存后立即生效。
- `bypassRule({id,minutes:15})` -> State；原生验证1..60，持久化绝对截止时间。
- `revokeBypass({id})` -> State。
- `clearLogs()` -> State。
- `getConfigJson()` -> String（格式化Config）。
- `exportConfig()` -> String|null，平台系统文件保存器导出Config，成功返回中文确认文本，取消null。
- `readImportFile()` -> String|null，系统文件选择器读UTF8 JSON，限制2MiB，取消null；此操作不修改配置。
- `importConfig({json:String})` -> State；必须用户在Flutter预览并确认后调用；原生完整校验且原子替换，清空usage/grants/waits/ack，保留日志。
- `openAccessibilitySettings()` -> null (Android)；用户主动阅读用途说明、同意后调用，不能自动开启。
- `openAppSettings()` -> null；Android应用详情，iOS系统设置。
- `openBatterySettings()` -> null (Android)，系统电池优化设置，不自动更改。
- `requestAuthorization()` -> Status (iOS)，由用户主动点击后调用真实FamilyControls授权；Android可不实现。

无桌面/Web生产运行：未支持平台的Bridge返回明确不可用状态并禁用执行，不能用模拟应用/计时作为真实功能。widget测试注入FakeBridge只在test文件。
