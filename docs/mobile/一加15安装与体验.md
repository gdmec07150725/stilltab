# 一加 15 / ColorOS 16 安装与体验

设备由用户提供；以下步骤尚未在该手机上实际验证。系统小版本可能改变菜单名称，以手机显示为准。

## 安装与授权

1. 将交付的 `behavior-rules-1.0.0-arm64-debug.apk` 通过 USB 文件传输等方式复制到手机，用文件管理器打开。若提示安装来源未授权，按系统弹出的入口允许当前文件管理器安装，再返回继续。
2. 打开 **行为规则 → 运行与备份 → 查看用途并设置权限**，阅读说明并点 **了解并前往设置**。
3. 在系统无障碍设置中找到 **行为规则 · 前台应用提醒**，自行开启。若未找到，在手机设置中搜索“无障碍”，查找本应用服务。
4. 返回应用，点 **刷新运行状态**；确认“无障碍权限”为“已授权”，“规则服务”为“已连接”。本版使用无障碍遮罩，不需要另外开启悬浮窗权限；服务不读取窗口文字或键盘输入。

若出现“受限设置”，先从 **运行与备份 → 应用系统设置** 打开本应用信息页，查看更多菜单是否提供“允许受限制的设置”，处理后再开启服务。Google 的该说明适用于 Android 13 及以上，ColorOS 的菜单位置可能不同；若没有该项，以本机提示为准。[Android 官方说明](https://support.google.com/android/answer/12623953)

## 先试一条 5 秒等待规则

1. “我的规则”右上角点 **＋**，名称填“打开前等 5 秒”。
2. 点 **选择应用组**，选择一个准备测试的普通应用。
3. 关闭 **限定生效时段**；**每日共享额度**填 **0 分钟**（打开即处理）。
4. 选择 **等待一下**，等待时间填 **5 秒**，提示内容填写“这次打开，是为了做什么？”。
5. 开启 **启用这条规则**并保存。新规则默认关闭，需主动开启。
6. 回到桌面，再打开测试应用。预期出现遮罩，等待结束后可点 **继续使用**。

同一次访问确认后不应反复弹出；切到其他应用再回来，会形成新的访问。编辑页预览不能代替跨应用测试。

- **临时放行**：规则右侧菜单 **规则操作（⋮）→ 临时放行 15 分钟**。提前结束可点 **结束临时放行**。只放行这条规则，其他命中规则仍有效。
- **停用**：关闭规则卡片开关。
- **停止全部执行**：在系统无障碍设置关闭该服务。
- **备份**：“运行与备份”可以导出规则；导入前显示预览和替换确认。备份不含用时、触发记录或临时放行。卸载会清除本机数据，更新前可先备份。

## 后台保持

先验证短流程。如锁屏或长时间后台后不触发，在“运行与备份”查看连接状态，再检查：

- **系统电池优化**：使用应用内同名入口，查找“行为规则”，按手机提供的选项允许后台运行或取消优化。
- 在手机设置搜索 **应用耗电管理**、**后台运行**、**自启动**，检查本应用对应项；存在相关开关时再配置并测试。

上述搜索词用于定位，未核实一加 15 国行 ColorOS 16 当前版本完整菜单路径，不保证每个选项都存在。OPPO 官方介绍过自启动管理入口；具体界面应按本机显示。[OPPO 自启动管理说明](https://support.oppo.com/co/answer/?aid=neu119)、[ColorOS 16 官方用户手册](https://www.coloros.com/service/instruction/coloros16)

## 真机检查（待执行）

| 检查 | 预期 |
| --- | --- |
| 在目标应用弹出、收起键盘 | 不误当作重新打开应用；输入法完整设置页面不残留目标应用遮罩 |
| 切到桌面或其他应用 | 旧遮罩消失；回到目标应用重新判断 |
| 锁屏 1 分钟再解锁 | 锁屏不计前台用时；后续实际切换应用后继续执行 |
| 1 分钟额度规则 | 只累计目标应用有效时段内前台用时；锁屏、等待/拦截遮罩不计入 |
| 临时放行与到期 | 放行期间该规则不触发；到期或提前结束后恢复 |
| 关闭规则/撤销服务权限 | 停止该规则/全部执行，遮罩不再出现 |
| 后台一段时间、重启 | 查看授权和服务连接状态，并实际打开目标应用测试，不仅看开关 |
| 文件操作中退出应用 | 不因重复回调崩溃；重新打开后可再次导入导出 |

等待期限按实际时钟保存，因此锁屏期间等待可能结束；这与锁屏不计用时并不矛盾。首次体验使用普通全屏应用，分屏、小窗、画中画需额外检查。
