# 设计与规则语义

## 目标与结构

面向普通用户的本地自律工具。弹窗负责当前网页状态和快速创建；管理页负责规则、模板、编辑、预览、记录和配置。无账号、云同步、远程接口和远程脚本。

MV3 服务工作线程是唯一状态写入方；消息操作串行执行。纯 TypeScript 规则引擎负责匹配、时段、冲突和计时分段。内容脚本在 document_start 注入，使用 Shadow DOM 隔离样式，以浏览器顶层原生 dialog 显示等待和拦截，提醒是非模态卡片。

## 匹配

仅处理 HTTP/HTTPS。整个网站按规范化域名匹配，忽略协议、端口、路径、参数和锚点；默认包含子域名，可关闭。子域名有点边界，example.com 不会命中 notexample.com。

网址路径按域名和路径段前缀匹配：`/news` 包含 `/news` 与 `/news/a`，不包含 `/newsletter`。忽略协议、端口、参数和锚点；路径区分大小写。

具体页面保留协议、端口和路径，包括结尾斜杠差异。默认保留 query、忽略 hash，高级设置可调整。域名不区分大小写，使用 URL 标准规范化国际化域名和点路径。query 参数顺序有意义，不进行语义排序。没有通配符、正则表达式或网页元素条件。

例外仅属于当前规则，命中后该规则既不处理也不计时，其他规则仍正常判断。例外支持相同的三种匹配方式。

## 时间和额度

使用本机时区和时钟。所选日的开始时刻包含、结束时刻不包含。开始=结束表示所选自然日全天。开始晚于结束表示跨午夜，例如周一 22:00–02:00 包含周二凌晨 00:00–02:00，周二 22:00 不属于此段。

不开时段限制表示每天全天。额度为 0 表示不使用额度门槛、满足链接和时段就处理；额度大于 0 时达到当日额度才处理。额度每日本地零点归零，即便跨午夜时段仍继续。只有规则启用、链接匹配且处于其时段内的前台可浏览时间才累计。同一条规则多个匹配页面共享额度；不同规则分别累计。

只计算当前有焦点的正常浏览器窗口中的活动 HTTP(S) 标签页。后台标签页、失焦窗口和系统锁屏不累计。浏览器前台但用户暂时没有键鼠操作仍视为阅读。等待和拦截界面不累计；仅提醒、已确认继续、临时放行继续累计。

内容脚本每秒发送心跳，后台重新核对焦点窗口和活动标签页。切换窗口、标签页、URL 会重新结算；所有事件串行避免重计。有效采样按分钟及本地午夜边界分段。超过 5 秒的未确认间隔整体舍弃，不把休眠/离线时间算作浏览。极高负载下可能少计；阈值触发通常约 1 秒延迟，非精密计费。

## 冲突与放行

按“拦截 > 等待 > 提醒”选择生效动作，再比较优先级数值（大者先）、创建时间（早者先）、规则 ID 字典顺序。先剔除例外、不在时段、额度未到、被放行的规则，再选最终规则。界面展示正在生效的规则名称和原因。

临时放行默认 15 分钟，作用于单条规则的所有匹配页面，其他规则继续生效；到期自动恢复，可提前结束，跨浏览器重启保留到期时间。期间仍累计符合条件的用时。

提醒确认和等待完成只放行该标签页当前完整 URL，刷新保留；离开 URL 后失效，关闭标签页或重启浏览器失效。URL 变化含 query/hash 变化，即使匹配时忽略参数也会被视为新的单次访问。等待按墙钟倒计时，切后台仍等待，完成后必须点击继续；工作线程休眠不丢倒计时。编辑规则会清除该规则单次放行和倒计时，并取消其临时放行。

## 数据与权限

chrome.storage.local 保存配置、最近 8 个有用时记录的日期、最多 300 条触发记录及临时放行到期时间；chrome.storage.session 保存各标签页 URL、确认状态、倒计时和前台计时采样点，服务工作线程休眠后恢复、浏览器重启后清空。时间基于绝对时间戳。

记录保存 origin + pathname（最多 2048 字符），不保存 query/hash，避免记录常见参数中的敏感信息。用户主动添加的精确匹配链接可包含 query/hash，存在规则及导出文件中。没有联网上传。

权限：storage 保存数据；tabs 识别当前页面；scripting 给已打开标签页注入；webNavigation 感知 SPA/锚点导航；alarms 在后台唤醒重新判断；idle 感知锁屏；HTTP(S) 主机权限用于在用户设置的网站运行内容脚本。未请求 cookies、history、webRequest 或下载权限。

导入严格验证字段类型和范围，最多 200 条规则、每条最多 20 个例外；规范化网址最多 2048 字符，格式化配置 UTF-8 总大小最多 2 MiB，不接受凭证网址、危险 ID 或不支持的版本。验证通过且用户确认后原子替换规则，同时清空用时/放行，保留历史触发记录。导出仅含 version 和 rules。

## 边界

这是自律辅助的页面访问遮罩，不是网络防火墙或家长控制。页面可能在遮罩出现前短暂显示或发起请求，页面脚本和后台请求仍可执行；扩展停用、卸载、开发者工具和恶意网页可绕过。遮罩会暂停当时可找到的音视频，但不能保证阻止所有媒体播放。

浏览器内部页、扩展商店、其他扩展页、文件网址、部分 PDF 阅读器等受保护页面无法处理；无痕模式默认未开启且首版未验收。对子框架不单独计时或建规则。系统时钟/时区变化影响时段、每日额度和到期时间。受浏览器节流影响，后台页面可最多等待约 30 秒的 alarm 再刷新规则状态，激活后每秒心跳恢复判断。
