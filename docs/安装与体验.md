# 安装与体验

## 安装

准备 Node.js 20+ 和 npm，在仓库根目录执行：

```sh
cd apps/extension
npm ci
npm run build
```

构建目录为仓库内的 `apps/extension/dist`。如使用单独取得的发布 ZIP，先解压到固定目录，不要直接在 ZIP 中加载；所选目录最外层必须有 manifest.json。发布归档不包含在 Git 源码中。

- Edge：地址栏输入 `edge://extensions`，开启“开发人员模式”，点击“加载解压缩的扩展”，选择 dist 文件夹。
- Chrome：地址栏输入 `chrome://extensions`，开启“开发者模式”，点击“加载已解压的扩展程序”，选择 dist 文件夹。
- 点击浏览器工具栏的扩展按钮，将“停一下 · 网页行为规则”（英文项目名 StillTab）固定到工具栏。
- 首次安装没有自动启用的示例规则。
- Manifest 要求 Chrome 120+；Edge 使用同一份构建。测试与未验证范围见 README 和发布包验证。

构建还会将运行文件同步到 `apps/extension` 根目录，以兼容已有本地安装；新安装建议加载 dist。未构建的 Git 源码目录不能直接作为扩展加载。

## 五分钟体验

1. 打开一个普通网页，点击扩展图标。弹窗显示当前网址、是否有规则生效和原因。
2. 选择“整个网站”“网址路径”或“具体页面”，点击“自定义…”进入规则编辑器（“创建提醒规则”会直接添加）。填写名称，选择“仅提醒”，设置提示语和按钮文字，先点效果预览，再保存。
3. 回到网页查看提醒。确认后刷新同一网址不重复提醒；跳转到其他网址再回来会重新提醒。
4. 将动作改为等待 5 秒。等待界面会显示生效规则，倒计时完成后才可继续；刷新保留进度。
5. 将动作改为直接拦截。网页显示阻挡界面，主按钮关闭当前标签页；在插件弹窗或管理页可临时放行 15 分钟，随后可提前结束放行。
6. 在“高级设置”添加一个例外链接。该规则不再处理例外页，其他规则照常判断。
7. 设置工作日和时段，或选择一个模板调整网站地址后保存。开启每日额度后，只有对应时段内前台浏览用时达到额度才处理。
8. 查看触发记录；在配置页面导出 JSON。导入前会预览规则数并确认覆盖，错误文件不覆盖原配置。配置总大小最多 2 MiB。

建议首次测试使用一个无未保存内容的普通网页；直接拦截主按钮的作用是关闭当前标签页。

## 页面说明

- 规则页：增删改、启停、今日用时、临时放行。
- 模板页：专注工作、每日半小时、打开前等待、睡前提醒。选择模板只打开编辑器，保存后才添加规则。
- 编辑器：点选范围、日期、时间、额度和动作。复杂匹配、例外、优先级按需展开。
- 触发记录：显示规则名称、动作、时间、网页和原因，最多保留 300 条。
- 配置页：导入导出规则，查看规则语义。导出不包含浏览记录或用时。

## 更新与卸载

更新构建后，在扩展管理页点击该扩展的刷新/重新加载按钮，然后刷新原有网页。保存的规则和用时保留；当前标签页的单次放行可能重置。卸载扩展会由浏览器删除扩展本地数据，需保留的规则请先导出。Chrome 与 Edge 的数据互不共享，可通过 JSON 迁移。
