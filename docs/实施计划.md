# 网页行为规则 · 第一版实施计划

目标：在桌面 Chrome / Edge 中，通过模板、句子式表单和按需展开的高级选项设置网页提醒、等待和拦截；所有数据仅本地保存。

技术：Manifest V3、TypeScript、esbuild、Node 测试。源码 apps/extension，文档 docs，最终 apps/extension/dist 与 ZIP。先交付本地体验，不发布。

- [x] 1. 规则引擎：建立类型契约；先测试网站/路径/页面/例外、跨午夜、优先级、额度、分段计时和导入验证，再实现纯函数。
- [x] 2. 用户界面：实现弹窗当前页状态/快速创建，规则列表与编辑、模板、预览、日志、导入导出。原生可访问表单，中文、浅色、蓝绿主色。
- [x] 3. 执行层：服务工作线程串行管理本地状态；内容脚本执行提醒/等待/拦截；处理导航/SPA/刷新/已有标签页，只有前台窗口活动页计时；后台休眠恢复不补计不确定时间。
- [x] 4. 验收交付：类型检查、引擎和集成测试、实际浏览器加载/截图、持久化与计时验证，打包并撰写安装及限制说明。

语义：例外属于单条规则。冲突顺序为拦截 > 等待 > 提醒，再按优先级数值降序、创建时间升序、ID 排序。每天额度按本地自然日归零；时段限制与额度叠加，额度到达才处理。结束时刻不包含；开始=结束视为所选日全天；跨午夜归开始日。网站匹配忽略协议和端口，路径匹配包含后代且有路径边界；精确页面默认忽略 hash、保留 query，高级设置可调整。仅支持 HTTP(S)。

临时放行：指定规则所有匹配页面，固定 15 分钟，可提前结束，跨浏览器重启保留到期时间；其他规则继续判断。提醒确认/等待完成：仅当前标签页的当前 URL 放行，刷新保留、离开该 URL 即失效，重启浏览器失效。等待按经过的墙钟时间，切后台仍倒计时。阻挡/等待界面不计入可浏览时长；提醒界面计时；临时放行仍计时。配置更改即时重新评估全部已打开页面。

重点风险与验证：恶意/损坏导入不覆盖原配置；SPA 和重复注入不产生重复界面；多窗口/后台标签不重计；跨午夜正确拆分；服务休眠/重启不补计离线时长。浏览器内部页、商店及部分受保护页无法注入，需明确显示。页面遮罩是自律辅助，不承诺网络防火墙或防绕过。

完成记录：36 项单元与后台队列测试通过，Edge 155.0.4283.45 完整验收 25 项通过，最终确认补丁 3 项针对性回归通过。Chrome 未完成功能验收。构建和 ZIP 校验通过；详细证据见验收报告。
