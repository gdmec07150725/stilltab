# 把「停一下」上传到插件商城

本文对应版本1.0.1。图标、名称、短描述已经写入插件；你需要完成自己的开发者账号验证和商店提交。当前没有提交审核，也没有上架。

## 先分清两个包

发布文件都在 `D:/code/behavior-rules/releases/extension/1.0.1/`。

| 文件 | 用途 |
| --- | --- |
| `pause-web-rules-1.0.1.zip` | **这是商店“上传扩展”要选择的文件**。ZIP最外层直接是manifest.json。 |
| `upload-kit-1.0.1.zip` | 资料合集，含插件包、图标、截图、文案、隐私页面和本说明。先解压到电脑，**不要把整个资料包作为扩展上传**。 |
| `store-assets/logo-128.png` | Chrome商店图标，128×128，已带透明留白。 |
| `store-assets/logo-300.png` | Edge商店图标，300×300。 |
| `store-assets/promo-440x280.png` | Chrome必填的小宣传图；Edge可选。 |
| `store-assets/screenshots/` | 1280×800的真实新版扩展界面截图。按文件序号上传。 |
| `store-assets/marquee-1400x560.png` | 可选大宣传图。 |
| `商店文案.md` | 可复制的长描述、单一用途、各权限理由和审核测试步骤。 |
| `privacy-site.zip` | 独立隐私政策网站，**只用于网页托管，不上传为扩展**。 |

不要上传旧的1.0.0包、源码目录、node_modules、手机APK，或者`.crx`/`.pem`文件。浏览器工具栏里的“打包扩展程序”不属于本次上架步骤。

## 1. 先获得公开的隐私政策网址

本插件虽然不上传数据，但会在本机处理网址、用时和规则记录，因此必须提供公开隐私政策。

按同目录 `隐私页面托管.md`，将 `privacy-site.zip` 拖到 Cloudflare Pages。成功部署后，你会得到自己的公开域名：Chrome填写域名下的 `/chrome.html`，Edge填写 `/edge.html`。先用未登录浏览器打开，确认能直接看到完整政策。不要填写本地D盘路径，也不要照抄示例域名。[Chrome官方用户数据FAQ](https://developer.chrome.com/docs/webstore/program-policies/user-data-faq)

已有个人网站也可以直接上传privacy-site目录内三个HTML文件，再使用对应页面的真实公网地址。不需要为这个静态页面购买域名。

## 2. 登录Chrome开发者控制台

打开 [Chrome Web Store开发者控制台](https://chrome.google.com/webstore/devconsole)。如果Google要求重新验证身份，在自己的浏览器中完成，不要把密码或验证码发给别人。

首次使用时按页面完成开发者注册、协议、一次性注册费、两步验证、联系邮箱验证和发布者信息。当前费用以付款页面为准；商家/非商家（Trader/Non-Trader）声明按你自己的实际身份和用途选择，不因为插件免费就自动选某一项。[官方注册说明](https://developer.chrome.com/docs/webstore/register)、[账号设置](https://developer.chrome.com/docs/webstore/set-up-account)

## 3. 新建条目并上传插件ZIP

在控制台点击 **Add new item / 添加新内容**，选择 `pause-web-rules-1.0.1.zip`，等待处理完成。

确认读取出来的信息：

- 名称：**停一下 · 网页行为规则**
- 版本：**1.0.1**
- 短描述：**为指定网站设置提醒、等待或拦截，按时段和每日额度管理浏览习惯。规则与记录仅保存在本机。**

出现“manifest缺失”时，先确认选中的是插件ZIP，不是资料合集或隐私网站ZIP。不要在插件ZIP外再套一层dist文件夹。

## 4. 填Store listing（商店详情）

- 主要语言选 **简体中文**，类别选页面实际提供的 **Productivity / 效率** 或相应分类。
- 从 `商店文案.md` 复制“完整功能描述”的正文；不要把文件标题、权限审核记录或“发布元数据”一起粘贴。
- 图标上传 `logo-128.png`。
- 截图从 `store-assets/screenshots/` 按编号选择，Chrome至少1张，最多5张。
- Small promotional tile上传 `promo-440x280.png`。
- 大宣传图若需要则上传 `marquee-1400x560.png`；视频、产品网站等未提供真实地址的可选项不要编造。

[官方商店详情说明](https://developer.chrome.com/docs/webstore/cws-dashboard-listing)、[官方图片尺寸](https://developer.chrome.com/docs/webstore/images)

## 5. 填Privacy（隐私）

从 `商店文案.md` 复制“单一用途说明”及对应权限理由。最终包申请的是：

`storage`、`scripting`、`alarms`、`webNavigation`、`idle`，以及HTTP/HTTPS网站主机权限。**新版已删除tabs权限，不要再给tabs填用途。**

- Remote code（远程代码）：**不使用**，功能代码全部随包提供。
- 隐私政策URL：填写第1步实际可访问的Chrome政策网址。
- 数据使用：按后台定义披露 **Web history / 网页浏览记录**（网址、触发网页路径）及 **User activity / 用户活动**（活动标签、用时、规则触发）。说明只在本机处理，不上传、不出售、不用于广告。
- 不要把“本机保存”理解为“完全不处理用户数据”，也不要选取实际不存在的健康、支付、身份验证或个人通讯数据类别。
- 阅读数据使用认证条款，确认与你实际的发布和后续运营方式一致后，由你勾选。

具体事实与适用类别见 `商店文案.md` 中“隐私表单填写依据”；若后台字段改变，以当前定义填写。[官方Privacy字段说明](https://developer.chrome.com/docs/webstore/cws-dashboard-privacy)

## 6. 选择分发范围并提交审核

在 **Distribution / 分发**中选择可用地区和可见性。要进入公开商城，选 **Public / 公开**。在测试说明栏粘贴 `商店文案.md` 的“审核测试说明”：本插件不需要测试账号，首次安装需要自己创建一条规则才会出现效果。

查看所有必填项是否完成，再点 **Submit for review / 提交审核**。若想审核通过后自己决定上线时间，关闭自动发布选项；审核通过后须在平台规定的期限内发布（当前官方为30天）。

**上传成功只是草稿，提交成功是等待审核，只有审核通过并发布后才是已上架。** 审核时间可能数天至数周，不能保证当天通过。[官方发布步骤](https://developer.chrome.com/docs/webstore/publish)、[审核流程](https://developer.chrome.com/docs/webstore/review-process)

## 7. 也发布到Edge（可选）

打开 [Microsoft Edge Partner Center](https://partner.microsoft.com/dashboard/microsoftedge/overview)，使用个人Microsoft账户作为所有者注册Edge开发者项目。Edge开发者注册目前免费，按提示填写真实账户类型、地区、发布者信息并完成协议；部分字段注册后不能更改。[官方注册说明](https://learn.microsoft.com/en-us/microsoft-edge/extensions/publish/create-dev-account)

新建扩展并上传**同一份** `pause-web-rules-1.0.1.zip`，依次填写 Availability、Properties、Privacy、Store listings 和测试说明。图标用 `logo-300.png`；截图可复用；中文长描述至少250字符。

Edge长描述不要写其他浏览器名称；提供的“完整功能描述”正文已使用通用表述，可直接复制。隐私政策填自己的 `/edge.html` 地址。名称与描述保持和最终manifest一致。

最后点击Publish提交认证；当前官方流程说明认证可达7个工作日，通过后自动上架。[Edge完整发布流程](https://learn.microsoft.com/en-us/microsoft-edge/extensions/publish/publish-extension)

## 只想先更新电脑上的图标

打开 `chrome://extensions` 或 `edge://extensions`，找到之前加载的“网页行为规则”，点该卡片的 **重新加载**。仍使用原来的 `D:/code/behavior-rules/apps/extension` 或其dist路径，不必先卸载，避免清除已有本机规则。若此前加载的是chrome-install目录，也已同步新版文件。

重新打开工具栏弹窗，应显示“停一下”；需要时将图标固定到工具栏。已打开网页中的旧提示可通过刷新网页重新载入。
