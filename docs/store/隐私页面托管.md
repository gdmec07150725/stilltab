# 隐私页面托管：用 Cloudflare Pages 手动上传

核对日期：2026-10-14。本步骤只上传已经准备好的静态 HTML，不需要编写代码、配置构建命令或购买域名。Cloudflare 官方的 Direct Upload 支持在控制台拖入一个目录或 ZIP。[官方说明](https://developers.cloudflare.com/pages/get-started/direct-upload/#drag-and-drop)

## 上传哪个文件

推荐上传这个单独的压缩包：

`D:/code/behavior-rules/releases/extension/1.0.1/privacy-site.zip`

也可以拖入这个目录：

`D:/code/behavior-rules/releases/extension/1.0.1/privacy-site`

压缩包根目录已包含以下三个文件：

- `index.html`：浏览器选择首页。
- `chrome.html`：Chrome 版完整隐私政策。
- `edge.html`：Microsoft Edge 版完整隐私政策。

上传时使用隐私页面 ZIP 或上述目录即可，不要上传浏览器插件 ZIP 或整个项目源码。页面不依赖外部 JavaScript、字体、图片或跟踪脚本。

## 手动上传

1. 登录 [Cloudflare 控制台](https://dash.cloudflare.com/)。没有账户时，先由你注册。
2. 打开 **Workers & Pages**，选择 **Create application → Get started → Drag and drop your files**。如果界面先让你选择 Workers 或 Pages，选择 **Pages** 的上传静态文件入口。
3. 输入你希望使用的项目名称，把上面的 `privacy-site.zip` 拖入上传区域。确认文件列表中的根目录能直接看到 `index.html`、`chrome.html` 和 `edge.html`。
4. 点击 **Deploy site**；如果页面随后显示 **Save and Deploy**，继续点击完成部署。
5. 部署完成后，复制控制台显示的生产站点 HTTPS 地址。Cloudflare 会提供 `pages.dev` 地址；以账户里实际生成的地址为准，不要把本文的文件路径填进商店。

以上按钮和上传方式按 [Cloudflare Direct Upload 文档](https://developers.cloudflare.com/pages/get-started/direct-upload/) 核实。控制台界面可能调整，核心入口是 Pages 的 **Drag and drop**。选择 Direct Upload 后，同一项目不能直接改成 Git 自动部署；本包不需要 Git。

## 保持公开可访问，再填写商店

隐私页面必须让未登录的人直接查看。将生产部署作为公开静态站点使用，不要给它启用 Cloudflare Access 登录保护或密码访问限制。

部署后，用浏览器无痕窗口分别打开以下地址进行检查：

| 用途 | 地址如何组成 |
| --- | --- |
| 首页 | 控制台实际显示的生产站点 HTTPS 地址 |
| Chrome 隐私政策 | 在该地址末尾追加 `/chrome.html` |
| Edge 隐私政策 | 在该地址末尾追加 `/edge.html` |

若站点地址末尾已有 `/`，不要再重复添加斜杠。部分托管平台会把 `.html` 地址自动跳转成不带扩展名的地址；只要能直接显示对应的完整政策正文，就可以复制最终地址。

Chrome Web Store 的 **Privacy policy URL** 填 Chrome 页，Microsoft Edge Add-ons 的同名字段填 Edge 页。两页都要能看到名称、更新日期、数据处理说明、删除方式和联系说明，不能出现 404、登录要求或下载文件提示。

**目前只准备好了本地文件，还没有部署，也没有生成公开 URL。** 按上面步骤完成后才会有可提交的网页地址。

## 后续更新

政策内容修改后，重新上传整个隐私页面包到同一个 Pages 项目的 **Create a new deployment**，选择 **Production**，继续沿用原有生产地址。

开发维护时，先修改 `D:/code/behavior-rules/docs/store/隐私政策.md`，再在项目根目录运行：

```powershell
node scripts/build-privacy-site.cjs
Compress-Archive -Path 'releases/extension/1.0.1/privacy-site/*' -DestinationPath 'releases/extension/1.0.1/privacy-site.zip' -Force
```

生成脚本会分别生成 Chrome 和 Edge 的适用范围，并检查 Edge 页面中没有 Chrome 政策内容。公开商店详情页还需要由发布者提供真实的开发者或支持联系方式；本包没有虚构邮箱和域名。
