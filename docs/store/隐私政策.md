# 停一下 · 网页行为规则隐私政策

更新日期：2026 年 10 月 14 日

本政策说明「停一下 · 网页行为规则」浏览器扩展如何处理数据，适用于该扩展在桌面 Microsoft Edge 和 Chrome 中提供的功能。

## 数据在本机处理

本扩展通过用户设置的规则提供网页提醒、等待倒计时和访问遮罩。扩展不要求注册账号，当前版本没有开发者服务器、遥测或云同步功能。规则判断、用时计算和记录保存均在使用者的设备上完成。

本机处理不代表扩展不访问用户数据。为实现这些功能，扩展会读取网页地址和浏览状态，并保存下述信息。

## 处理哪些信息，以及为什么处理

**规则设置。** 保存你创建或导入的规则，包括规则名称、匹配网址、例外网址、时段、每日额度、处理方式、等待时长、自定义提醒文字、按钮文字、优先级和启用状态，用于执行和管理你选择的规则。精确页面规则中的网址可能保留查询参数和锚点；自定义文字也会按你的输入保存。

**网页地址与浏览状态。** 读取打开标签页的地址、活动标签页、浏览器窗口焦点和系统锁屏状态，判断规则是否适用，以及哪些时间应计入前台浏览用时。当前浏览器会话中会暂存各标签页的完整网址、确认状态、等待截止时间及计时采样点，用于避免重复提醒和恢复等待进度。扩展不读取安装前的浏览器历史记录。

**每日用时。** 按规则和本机日期保存符合条件的前台浏览时长，供每日额度和用时显示使用。后台标签页、失去焦点的浏览器窗口、锁屏、等待和拦截期间不累计用时。

**触发记录。** 保存规则触发或临时放行的时间、规则名称、处理方式及原因，帮助你查看规则何时生效。触发网址仅保存来源和路径，最多 2048 个字符，不保存查询参数和锚点。网址路径仍可能包含个人信息，因此这些记录不应视为匿名数据。

**临时放行。** 保存被临时放行的规则及到期时间，使放行持续至到期或由你提前结束。

扩展不抓取网页正文、表单输入、私人消息、图片或音视频内容，不记录键盘输入内容、鼠标点击轨迹或屏幕截图。为了显示提醒和遮罩，扩展会在网页中添加自己的界面，并尝试暂停该网页中当时可找到的音视频元素。显示在网页上的规则名和提醒文字属于页面可见内容，请勿在这些文字中填入密码等秘密信息。

## 保存位置与保留期限

规则、每日用时、临时放行和触发记录保存在该浏览器个人资料中的扩展本地存储。当前版本保留最近 8 个有用时记录的日期，以及最多 300 条最近触发记录；这不等同于自动删除所有超过 8 个日历日的数据。

规则保留至你删除或替换规则，或移除扩展。过期的临时放行会在扩展重新判断状态时清理。浏览器会话数据使用会话存储，关闭相关标签页会移除该标签页状态，重启浏览器后重新建立会话状态。

扩展未对本地存储和导出的 JSON 额外加密。这些数据的保护依赖设备、操作系统和浏览器个人资料的访问控制。

## 数据传输、分享与使用限制

当前版本不通过扩展向开发者或第三方上传规则、网址、用时或触发记录，不出售这些数据，也不将其用于广告、用户画像、信用判断或贷款用途。扩展不使用广告或分析服务，也不加载远程功能代码。

本扩展对用户数据的使用仅限于上述用户可见功能，遵守 Chrome Web Store 用户数据政策，包括其 Limited Use 要求。开发者不会通过扩展远程读取你的本地数据。

扩展中的提醒界面会显示在你当前访问的网页内；网站自身的脚本可能读取页面中显示的内容。扩展不主动向网站发送这些提示内容，也不能控制网站自身如何处理其能够访问的网页内容。

浏览器、扩展商店及你访问的网站各自可能处理数据，这些行为由相应服务的政策约束，不属于本扩展的数据上传功能。

## 你可以如何查看、删除和导出数据

你可以在管理页查看、修改、停用或删除规则，在「触发记录」中查看并清空记录，在弹窗或管理页提前结束临时放行。

删除一条规则会同时删除该规则的用时和临时放行状态，已有触发记录仍会保留，直至你清空记录或它们被更新的记录替换。导入配置会在预览并确认后替换全部规则，重置用时和放行状态，但不会清空已有触发记录。

「导出配置 JSON」只导出规则设置，不包含触发记录、每日用时或临时放行。你主动保存、传输或分享该文件时，文件中的网址和自定义文字也会随之保存、传输或分享。扩展不会自动把备份发送到其他设备或云服务；已导出的文件需要你自行删除。

你可以在浏览器扩展管理页面停用或移除本扩展。停用后扩展停止继续处理网页；移除扩展会由浏览器清除其扩展存储，但不会删除你此前导出的文件或设备备份。

## 政策更新与联系

功能和数据处理方式发生变化时，本政策将同步更新，并修改顶部日期。涉及数据处理用途或范围的重要变化会通过扩展或商店说明向用户披露。

如需联系开发者，请使用本扩展商店详情页中列出的开发者或支持联系方式。反馈时无需发送你的完整规则备份或浏览记录；由你决定是否提供排查问题所需的具体内容。
